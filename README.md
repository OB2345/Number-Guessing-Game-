# 🎯 Number Guessing Game (Python CLI)

A feature-rich command-line interface (CLI) game built with Python. The game generates a random number between 1 and 100 and prompts the player to guess it, providing dynamic "Too high" and "Too low" hints while enforcing attempt limits and user input validation.

---

## ✨ Features

- **🛡️ Defensive Error Handling:** Uses `try/except` blocks to prevent crashes when invalid inputs (e.g., text or symbols) are entered.
- **🎯 Dynamic Hint Logic:** Tells players whether their guess is too high or too low.
- **⏱️ Limited Attempts:** Set to a maximum of 10 attempts per game round.
- **🏆 High-Score Tracking:** Tracks the player's best score across multiple games in a single session.
- **🔄 Replayable Game Loop:** Prompt to play again without restarting the script.
